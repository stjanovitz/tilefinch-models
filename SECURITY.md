# Security policy

Please report vulnerabilities in Tilefinch optional-component parsing,
signing, download, installation, or packaging through the private reporting
instructions in the
[main Tilefinch security policy](https://github.com/stjanovitz/tilefinch/blob/main/SECURITY.md).

Do not include exploit details, private keys, or unpublished component files
in a public issue. General feature requests and non-security packaging bugs
may use the ordinary issue tracker after the repositories become public.
